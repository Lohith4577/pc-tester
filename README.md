# PC Tester

A simple Python tool to display your PC specs and run quick benchmarks.

## Features
- System information (CPU, RAM, Disk, OS)
- Quick CPU and Memory benchmarks
- Overall performance score

## Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/Lohith4577/pc-tester.git
   cd pc-tester
   ```

2. Install dependencies:
   ```bash
   pip install psutil
   ```

3. Run the tester:
   ```bash
   python pc_tester.py
   ```
